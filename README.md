# 🌍 WorldCountriesApp

A beautifully simple iOS app built with **SwiftUI**, **Combine**, and **MVVM Clean Architecture**.  
Search and explore countries, view details like capital and currency, and build your own curated list — even works offline.

## 🧠 Features
- Fetch data from [REST Countries API](https://restcountries.com/v2/all)
- Search and filter countries by name
- View details (capital, currency)
- Add or remove up to 5 favorite countries
- Automatically detect your country via GPS
- Offline caching (UserDefaults)
- Built with clean MVVM + Combine

## ⚙️ Tech Stack
- Swift 5+
- SwiftUI
- Combine
- CoreLocation
- REST API (JSON)
- Unit Testing
